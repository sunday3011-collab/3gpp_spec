## SRS antenna switching 4T8R 技术问答（基于本地 R18 spec）

- 解答了 4T8R SRS antenna switching 的配置与发送机制，随后给出典型周期配置实例。
- 关键条文位置（本地 `3gpp-wiki/raw_sources/specs/`）：
  - 38.214 j30 line 5433-5441：4T8R 配置规则（1个periodic set，2个resource×4port，同slot不同symbol，Y=1 guard @30kHz）；line 5440 同slot仅1个antennaSwitching set；line 5442-5450 Table 6.2.1.2-1 guard Y值表。
  - 38.331 j20 line ~40395：supportedSRS-TxPortSwitchBeyond4Rx-r17 11-bit bitmap（bit8=t4r8）。
  - 38.211 j30 §6.4.1.4 line 3341：startPosition 从 slot 末尾倒数。
- 典型配置结论：1个periodic SRS-ResourceSet（usage=antennaSwitching），含2个SRS-Resource各ports4；resource0 startPosition=2→symbol 11（天线0~3），resource1 startPosition=0→symbol 13（天线4~7），symbol 12为guard；4端口单symbol需comb-4（K_TC=4）。
- 追问"同slot完成天线切换SRS是否有能力bit"：结论分场景——1T4R aperiodic有 `srs-OneAP-SRS-r17`（1个AP set、4 resource同slot，依赖 srs-StartAnyOFDM-Symbol-r16，38.306 line 2025 / 38.214 line 5414）；Rel-15基线1T4R AP必须跨2 slot（line 5417）；`srs-ExtensionAperiodicSRS-r17`是反方向（扩展跨slot set数）；4T8R/2T4R/1T2R等2-resource形态同slot为基线隐含能力，无单独bit（2 SRS+1 guard=3 symbol放得进最后6 symbol）。symbol预算：1T6R=11、1T8R=15、2T8R=7超窗，必然跨slot或需StartAnyOFDM。
- 追问"4T8R是否强制1个slot发2个SRS"：**不强制**。38.214 line 5434：aperiodic两种形态均合法——1个set含2 resource同slot不同symbol（中间Y guard），或2个set各1 resource跨2个不同slot；且4T8R的2个AP set跨slot形态**不需要**srs-ExtensionAperiodicSRS（对比1T2R/2T4R line 5402/5408需要该bit才能配2个AP set）——beyond4Rx能力的AP set数是基线放开。P/SP（line 5433）条文只写"different symbols"，同slot为典型实现；line 5440约束同slot最多1个antennaSwitching set。
